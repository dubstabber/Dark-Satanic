# Dark Satanic

Arena survival FPS in the vein of *Devil Daggers*, wearing a *Sad Satan* skin: monochrome, grainy VHS,
dithered, gothic, one hit and you are gone. Built with Godot 4.7.1 (GDScript).

## Run

```sh
tools/run_game.sh          # play
tools/run_game.sh -e       # open the editor
```

The Godot binary is looked up via `GODOT_BIN` (default `./Godot_v4.7.1-stable_linux.x86_64`, git-ignored).
`tools/run_game.sh -- --autostart` skips the menu.

## Controls

WASD move · mouse look · hold **LMB** dagger stream · **RMB** shotgun burst · **Space** jump (hold to bunny-hop,
jumping on landing gains speed) · **Esc** pause · **R** retry after death · **F11** / **Alt+Enter** fullscreen (also in Settings, persisted). Gems dropped by nests and big skulls
upgrade the daggers at 10 / 70 / 220 gems; any touch kills you; the platform shrinks from 60 s on.

## Test

```sh
tools/run_tests.sh                       # full GUT suite, headless, deterministic (--fixed-fps 60)
tools/run_tests.sh -gdir=res://tests/unit/ -gselect=wave_table
tools/smoke_test.sh                      # boots the real binary and greps the log for errors
tools/check_script_sizes.sh              # NOTE > 300 / 500 lines, WARN > 700, FAIL > 900; autoload-usage rule
```

Tests never touch the real `user://` files: `GameTest` points `SettingsManager` at a temp file and every
`temp_user_path()` is deleted afterwards.

## Layout

- `src/core` autoloads, `GameFlow` state machine, `main.tscn`, run state
- `src/components` reusable Health / Hurtbox / Hitbox / Spawner / GemDrop / DeathHandler nodes
- `src/player`, `src/weapons`, `src/enemies`, `src/spawning`, `src/pickups`, `src/arena`, `src/vfx`, `src/ui`,
  `src/persistence`, `src/game` — one feature per folder, scenes + Resources for all tuning
  (the UI theme lives in `src/ui/theme`)
- `assets` audio (generated by `tools/gen_audio.sh`, stored in git LFS; `assets/audio/cues/*.tres` are the
  designer-facing `AudioCue`s), fonts, `models` (Tripo `.glb` sources + the `meshes/*.res` Godot saves from
  them on import), `textures` (greyscale albedos baked by `tools/bake_textures.py`, needs ImageMagick 7) and
  `source` (originals Godot does not import: `.blend`, the raw floor photo)
- `tests/unit`, `tests/integration`, `tests/e2e` (GUT 9.7.1); shared bases/helpers in `tests/support`

Conventions live in `CLAUDE.md`; the module contracts in `docs/architecture.md`.
